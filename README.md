# VPN-SubFiles

##  Использование

### Для пользователей

1. Открой страницу: [https://mrbober42-lgtm.github.io/VPN-SubFiles/](https://mrbober42-lgtm.github.io/VPN-SubFiles/) (если настроен GitHub Pages) или перейди по ссылке на `index.html`.
2. Нажми кнопку **«Добавить подписку»** — откроется HApp с предложением добавить подписку.
3. Либо скопируй ссылку `happ://add/https://raw.githubusercontent.com/mrbober42-lgtm/VPN-SubFiles/main/subscription.conf` и добавь вручную в HApp как подписку.

### Для разработчиков

- Файл `subscription.conf` можно редактировать, добавляя или удаляя строки с `vless://`.
- Метаданные подписки задаются в строках, начинающихся с `#`:
  - `#profile-title` — название подписки.
  - `#support-url` — ссылка на поддержку.
  - `#announce` — объявление.
  - `#subscription-userinfo` — информация о трафике (опционально).
  - `#profile-update-interval` — интервал автообновления в часах.

## 🛠 Технические детали

- Формат подписки: список `vless://` ссылок с метаданными в комментариях.
- Совместимость: HApp (iOS/Android).
- Акцентный цвет страницы: `#7c71ff`.

##  Файлы

- **`index.html`** — целевая страница для добавления подписки. Открывается по ссылке, автоматически или по кнопке вызывает схему `happ://add/` с URL подписки.
- **`subscription.conf`** — основной файл подписки в формате, который понимает HApp. Содержит метаданные (название, поддержка, объявление) и список серверов в формате `vless://`.
- **`subscription.json`** — альтернативный файл подписки в формате JSON для импорта в качестве конфигурации (без метаданных подписки).
